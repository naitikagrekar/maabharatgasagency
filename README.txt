MAA BHARAT GRAMIN GAS AGENCY — YELLOW + BLUE WEBSITE

FILES
- index.html : website content
- style.css  : yellow + dark-blue professional design
- script.js  : mobile menu and automatic copyright year

HOW TO OPEN IN VS CODE
1. Extract the ZIP file.
2. Open VS Code.
3. Select File > Open Folder.
4. Select the extracted folder: maa_bharat_gas_yellow_blue
5. Open index.html.
6. If you have Live Server installed, right-click index.html and choose
   "Open with Live Server". Otherwise, double-click index.html to open it
   in your browser.

EDITING CONTACT DETAILS
The current agency phone numbers and Garhi address are already added in
index.html. Search for the number or address in that file to edit them.

ADDING YOUR AGENCY LOGO
The top-left brand mark is currently a simple built-in icon. When you have
your logo image, place it in this folder and replace the brand-mark element
in index.html with an img tag. Example:
<img src="logo.png" alt="Maa Bharat Gramin Gas Agency logo">

NOTE
This is a front-end informational website. It does not process LPG bookings
or collect customer information. Confirm service details and emergency
contact information with your LPG provider before publishing.
